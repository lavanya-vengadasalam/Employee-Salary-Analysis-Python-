# Employee Salary Analysis

## Project Overview
This Python mini project analyzes employee salary data to generate a salary report and answer basic employee-related questions.

## Project Objectives
- Calculate the total salary of all employees.
- Calculate the average salary.
- Identify the minimum and maximum salaries.
- Find employees earning 70,000 or more.
- Identify employees working in the IT department.
- Count employees earning more than the average salary.

## Technologies Used
- Python
- Visual Studio Code
- GitHub

## Python Concepts Used
- Variables and data types
- Lists and dictionaries
- For loops
- Conditional statements
- List comprehension
- Built-in functions: `len()`, `sum()`, `min()`, and `max()`
- List methods: `append()`

## Files Included
- `employee_salary_analysis.py` – Python program for employee salary analysis.

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run `employee_salary_analysis.py`.
5. View the report in the terminal.

## Expected Results
- Number of employees: 5

- Average salary: 65,000
- Minimum salary: 45,000
- Maximum salary: 85,000
- Employees earning 70,000 or more: 2
- Employees in IT: John, Rahul, and David
- Employees earning more than average salary: 2
